<p>I Developed PookieWookie as a school programming project, beginning with a paper-based plan that mapped out the game’s structure, progression system, available actions, and player statistics before any code was written. The concept was then translated into a Java console-based life simulation where players progress through different stages of life by entering commands and deciding how to spend their available actions.

The game tracks several interconnected variables, including health, happiness, intelligence, cash, assets, age, education, employment, and inventory. Player decisions can increase or decrease these values, creating trade-offs between earning money, improving stats, attending school, working, and participating in other activities.

Every set of commands represents a period of the character’s life, allowing the player to age and gradually unlock new opportunities. For example, employment becomes available only after reaching a certain age, while individual jobs have their own intelligence requirements and hiring mechanics. The game also uses age-dependent random events that can positively or negatively affect the player's health, happiness, intelligence, and finances, making each playthrough less predictable.

The project gave me experience designing a larger program around state management, conditional logic, methods, random events, user input, progression systems, and interconnected gameplay mechanics, while also showing me the importance of planning a software system before beginning implementation.</p>
